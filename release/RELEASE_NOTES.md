# Manifold 0.11.2 — first public preview

Powered item networks, portable storage and real-machine autocrafting, with regional trains and optional Space Age logistics. Original industrial machines animate while powered and active.

This release adds the missing in-game/mod-portal thumbnail, current descriptions, illustrated installation and gameplay documentation, explicit compatibility limits and a clean release package. Gameplay and animation behavior are unchanged from 0.11.1; the vanilla crafting quality selector now displays Normal correctly.

## Download and install

Download **manifold_0.11.2.zip** and put it, unextracted, in your Factorio mods folder. Enable Manifold and restart. The adjacent SHA-256 file verifies the download. GitHub's automatic source archives are not installable mods.

Requires Factorio **2.0.77 or newer within 2.0**; Factorio **2.1 is not supported**. Space Age and Quality are optional. English UI. Original mod code and artwork: MIT.

## Preview limits

Multiplayer, long campaigns, arbitrary overhaul mods and full rocket/platform voyages remain unverified. Autocrafting is limited to deterministic, single-result nonfluid item recipes without modules; perishables stay outside digital storage/crafting/train reservations. The original five-stage vision is only partially implemented: this release has three transport hardware tiers. See the linked player guide and known limitations before planning a factory around it.
